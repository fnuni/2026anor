ROLE
You generate one deterministic heuristic function for the specified operations-research
problem. You will be called several times; produce a different algorithmic idea each time.

PROBLEM
Fuzzy field-service / parallel-machine scheduling with a convex overtime penalty.
n independent work orders must be partitioned among an unlimited number of identical
technicians, each working one shift. For a technician whose realised load is L the cost is

    technician_cost + L + overtime_rate * max(0, L - shift)

and the instance cost is the sum over the technicians actually opened. Task durations are
imprecise: each task j carries a modal duration proc[j] and a volatility volatility[j]
inherited from its congestion zone zone[j]. A scenario scales every task of zone g by a
common-mode factor, so tasks sharing a zone move together.

INTERFACE
    def solve(instance, params):
        ...
        return machines      # list of lists of task indices

instance is a read-only dict with keys:
    n                 int, number of tasks
    proc              list[float], modal durations, length n
    volatility        list[float], per-task volatility in [0, ~1], length n
    zone              list[int], congestion zone of each task, length n
    shift             float, regular shift length
    overtime_rate     float, convex multiplier beyond the shift
    technician_cost   float, fixed cost of opening one technician

params is a read-only dict with keys orness, alpha_grid, train_spread.

The returned partition must cover every task index 0..n-1 exactly once. Empty technicians
are not allowed.

ALLOWED OPERATIONS
Pure Python and the math module only. No imports other than math. No file, network,
subprocess or global state. No attribute whose name starts with an underscore. The function
must be deterministic and must return within two seconds for n up to a few hundred.

OBJECTIVE
The evaluator will execute the same code over an alpha-cut scenario ensemble and score it on
mean cost, ordered-weighted tail risk and inter-scenario dispersion. It is the evaluator, not
this prompt, that defines success.

TASK
Produce one compact, self-contained heuristic. Output only the Python source.
